# 地轮静摩擦（死区）标定

`GROUND_DEADZONE_PWM`（默认 1800）是**估计值**，来自"用户口述约 2000、打折保险"。
它只在闭环输出非零时同方向叠加，跟随 1 秒启动斜坡，最终仍受 `GROUND_PWM_LIMIT` 限制，
静止（输出恰为 0）时不叠加。要让这个数变成实测值，按下面的步骤量。

## 为什么必须实测

地轮是"有刷电机 + 减速箱 + 轮胎"，死区不是一个固定常数：

- 正转和反转的静摩擦不一样（减速箱斜齿轮的轴向力方向不同）；
- 轮胎压地、车重、胎温、电池电压都会改变它；
- 2000 这个数是从"倒地过程中指令 −4000、编码器仍为 0"反推的，那时车架可能已经触地、
  轮子被卸掉一部分载荷，**很可能高估**。

所以先用一个偏保守的常数（1800）保证能起步，再用实测值收敛。

## 台架准备

1. 车立起来，让地轮着地、承载正常车重；两侧飞轮悬空或拆掉输出（`FLY_PWM_LIMIT` 可在菜单里临时改 0，
   或者直接用 Mode8 只给地轮 PWM）。
2. 手扶车架不让它前后倒（或用两根限位杆），**不要**让它自己找平衡。
3. 打开上位机，订阅 `TV_fault_reason`、`TV_rate_state`、`TV_imu_status`、编码器计数/速度通道，方便看现象。

## 测量步骤（Mode8 开环，最干净）

Mode8 不走 PID、不要求 IMU 就绪，给多少 PWM 就是多少（受 `DEBUG_PWM_LIMIT` 与 1 秒启动斜坡约束）。

1. 进 Mode8（菜单），确认 `roll_rate_test_state` 已退出（`shacheflag=0`）。
2. 从 0 开始，每次把 `pwm_debug_ground` 加 100，保持 1 s，记录编码器是否开始变化。
3. 记下"第一次开始转"的 PWM，就是该方向的 **breakaway**；正反各做 3 次。
4. 再从大往小减，记录"开始不转"的 PWM，得到 **迟滞**（回差）。
5. 每次都等启动斜坡走完（`TV_startup_scale` 到 1.0）再读，否则读到的是被斜坡压小的值。

> 注意：Mode8 的斜坡同样按 `BALANCE_STARTUP_RAMP_MS` 放开上限，1 秒内给 4000 实际只有一部分；
> 要么等 1 秒，要么在 `config.h` 里把 `BALANCE_STARTUP_RAMP_MS` 临时改 0 再编译（测完改回来）。

## 结果怎么用

- 取正反两个方向 breakaway 的**中位数**，四舍五入到 50 的倍数，写进 `code/config.h`：

  ```c
  #define GROUND_DEADZONE_PWM 1800.0f   /* 实测中位数，例如 1650 */
  ```

- 两个方向相差超过 30% 时，单一常数只能取保守值（偏大的那个会让另一方向过冲）。
  需要分方向补偿的话，下一步可以把 `ground_deadzone_shape()` 改成
  `sign(pwm)>0 ? GROUND_DEADZONE_PWM_FWD : GROUND_DEADZONE_PWM_REV`，两个常数分别标定。
- 迟滞（回差）不用单独补偿：输出过零时直接回 0，本来就跳过了回差区间。

## 验证

1. Mode5 立柱，静态放手：不应出现原地左右低频来回蹭（limit cycle）。出现就说明常数偏大，
   每次减 200 再试。
2. 给一个小角度扰动：地轮应立刻有动作、编码器不再长时间为 0。
3. 看 `TV_motor_ground_pwm`：静止且误差为 0 时应为 0；有微小误差时应直接跳到 ±1800 附近，
   而不是缓慢爬升。
4. Mode2 位置保持：能起步但不应持续冲过目标点来回振荡；振荡则先降死区常数，再考虑
   `WHEEL_SPEED_KP`。

## 关闭方式

- 编译期：`GROUND_DEADZONE_PWM` 设 `0.0f`。
- 运行期（调试用）：`ground_deadzone_enable = 0;`（`balance_control.h` 里有 extern）。
